# SCP – Wissenschaftler-Handbuch

Statische Website (eine Datei: `index.html`), bereit für GitHub Pages. Kein Build nötig.

## Veröffentlichen in 5 Schritten

1. Auf github.com einloggen und **New repository** anklicken. Name z. B. `scp-wissenschaftler`, Sichtbarkeit **Public**, erstellen.
2. Im neuen Repository **Add file → Upload files** wählen und `index.html` hineinziehen (die ZIP vorher entpacken). Mit **Commit changes** bestätigen.
3. Oben **Settings → Pages** öffnen.
4. Bei **Source** „Deploy from a branch“ wählen, Branch `main` und Ordner `/ (root)`, dann **Save**.
5. Nach ca. 1–2 Minuten ist die Seite erreichbar unter:
   `https://DEIN-BENUTZERNAME.github.io/scp-wissenschaftler/`

Die Menünamen bei GitHub können sich leicht ändern. Ändern kannst du die Seite später, indem du `index.html` im Repository bearbeitest (Stift-Symbol) und speicherst.
